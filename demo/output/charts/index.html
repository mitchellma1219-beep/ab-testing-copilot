A/B Testing Copilot: demo charts

Generated by python demo/run_demo.py from seeded synthetic data. Each page works offline and has a table view of its numbers.

  • Effects with intervals
    Conversion lift of +1.5 pp, no guardrail effect, valid randomisation. The recommendation is Ship.
  • A/A check on the same data
    Units are re-labelled at random 1,000 times and the test is repeated. Every rejection is a false positive, so the bars should be flat and about 5% of the p-values should fall below 0.05.
  • Treatment effect over time
    The lift starts at +6 pp and halves every 3 days: early enthusiasm that fades. The check reports the trend as a warning with its evidence, never as proof.
  • Exploratory: effect by segment
    The lift is +3 pp on mobile and zero on desktop and tablet. Segment results are hypotheses for a follow-up test and never change the recommendation.
  • Sequential stopping boundaries
    Four planned looks with O'Brien-Fleming-type alpha spending. At look 2 the z statistic is 2.55: a fixed 5% test would call it significant, the boundary (2.96) does not, and the experiment continues.
  • Power curve
    Baseline conversion 10%, minimum detectable effect 1 percentage point, alpha 0.05: 80% power needs 14,751 users per arm.
  • P-values when there is no effect
    4,000 simulated experiments with a true effect of zero (conversion 10%, 5,000 users per arm). The histogram is flat and 5.1% of the p-values are below 0.05.
  • Simulated confidence intervals
    The first 100 of those simulated experiments: 95 of the 95% intervals contain the true effect of zero.
  • False-positive rate by analysis rule
    No true effect, five equally spaced looks, 4,000 simulated experiments per rule. Repeating a fixed test inflates false positives; the spending boundaries keep them at alpha.
